# LLM & Harness

面向 LLM 与 Harness 的私有学习、研究与实践知识库。

## 目的

- 系统整理 LLM、Agent、Harness、工具调用与评测相关知识
- 将零散的探讨和交流沉淀为可查询的文档、案例与实验记录
- 逐步形成可复用的课程、学习路径和实践方法

## 内容规划

- `courses/`：课程与学习路径
- `notes/`：主题笔记与讨论记录
- `experiments/`：实验、原型和结果
- `references/`：参考资料与链接
- `projects/`：可复用项目与实践案例

## 状态

本仓库暂为私有仓库，内容结构和课程体系将随着讨论持续迭代。
