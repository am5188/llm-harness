# 前置课总计划：大语言模型为何出现

## 这门课真正要回答的问题

不是“模型发布了哪些版本”，而是：**为什么在 2022 年前后，机器第一次以大众可用的方式表现出强大的语言能力；为什么这条路在美国先形成产品突破；为什么 2023 年后开放权重扩散；以及这些模型为什么继续演化为 RAG、工具调用、Agent 和 Harness。**

时间线只是骨架，解释才是课程主体。

## 三条主线，最终在一个产品上汇合

### 1. 智能观念线：人们如何定义“机器会思考”

从图灵 1950 年的模仿游戏开始，追踪符号主义、专家系统、连接主义、统计学习和神经网络。重点不是宣布“学院派失败、涌现派胜利”，而是说明不同路线对智能的假设：规则与推理、表示与学习、数据与规模、交互与反馈。

### 2. 可行性线：什么条件让模型终于能训练出来

追踪算法、数据、GPU/加速器、网络、能源、分布式训练、上下文窗口、优化方法和评测。每次突破都回答：此前哪一个瓶颈被移除了？成本是什么？规模扩大带来了什么新能力，又带来了什么新问题？

### 3. 产业与组织线：谁有能力把研究变成产品

追踪大学、实验室、创业公司、云厂商、芯片厂商、资本、数据标注和监管。中美比较不写成“谁更聪明”，而写成研发组织、资本耐心、芯片与云、开源策略、市场分发和政策约束的差异。

## 课程章节

### 第一编：问题的诞生（1950–2011）

1. 图灵与模仿游戏：测试的原文究竟主张什么
2. Dartmouth 与人工智能作为学科
3. 符号主义、专家系统和两次 AI 冬天
4. 感知机、反向传播、统计学习与连接主义复兴
5. 为什么早期方法没有产生通用语言能力

**本编结论**：目标很早就出现，但缺少数据、算力、可扩展训练方法和可用的产品反馈。

### 第二编：深度学习成为可扩展工程（2012–2017）

6. ImageNet、GPU 和深度网络
7. 词向量、RNN、seq2seq 与注意力
8. Transformer：它解决的是并行训练和长程依赖，不是凭空创造智能
9. Google、学术界与工业研究的关系

**本编结论**：语言建模从“设计特征”转向“学习通用表示”，训练规模第一次有明确的扩展方向。

### 第三编：预训练与规模化（2018–2021）

10. BERT、GPT-1、GPT-2：预训练—适配范式
11. GPT-3 与少样本能力
12. scaling laws：参数、数据和计算预算
13. InstructGPT、SFT 与 RLHF：从会续写到会对话
14. OpenAI、微软 Azure 与前沿模型组织

**本编结论**：能力不是单一算法的结果，而是架构、数据、计算、训练配方和资本共同作用。

### 第四编：ChatGPT 作为分水岭（2022）

15. Chinchilla：为什么“更大”不等于“更好”
16. ChatGPT 的产品化：模型、对齐、界面和分发
17. 为什么是 2022 年，而不是 2020 年
18. 资本、云计算、人类反馈和安全工作的供应链
19. “涌现”到底是现象、解释还是宣传叙事

**本编结论**：ChatGPT 是研究积累、计算规模、对齐技术和产品设计同时成熟的结果。

### 第五编：开放权重与竞争扩散（2023–2025）

20. Anthropic 从 OpenAI 分离：安全理念、治理与组织分歧
21. GPT-4、Claude、Gemini 与前沿模型竞争
22. Meta LLaMA：开放权重、许可证和生态扩散
23. Mistral、Qwen 等开放模型
24. DeepSeek 与 High-Flyer：组织背景、效率路线和技术报告
25. 中国路径：算力约束、应用场景、政策和工程能力
26. 美国路径：中国竞争与芯片出口限制

**本编结论**：开放权重改变了“只有少数公司能训练和研究”的门槛，但并不等于训练成本消失。

### 第六编：从一次 API 调用到 Harness（2020–2026-10-01）

27. 单轮 completion/chat API 与上下文窗口
28. 长上下文、会话状态和记忆压缩
29. RAG：把外部知识放入生成过程
30. ReAct、工具使用和 function calling
31. 多步循环、错误恢复、规划、状态和权限
32. Agent 与 Harness 的边界：模型能力之外的系统工程
33. 评测、可观测性、安全和成本控制
34. 截止 2026-10-01 的阶段性总结（只写已发生且可验证的事件）

**本编结论**：当模型不能可靠地记住、检索、执行和验证时，系统就必须用 Harness 把一次生成变成可控的工作流。

## 每章固定结构

1. 当时的问题是什么？
2. 主流路线有哪些？它们对“智能”的假设是什么？
3. 哪个瓶颈被解决，代价是什么？
4. 关键论文、产品、公司和资本事件
5. 美国与中国的异同
6. 这一阶段如何导致下一阶段
7. 证据表：事实、来源、原文定位、可信度
8. 本章仍不能确定什么

## 交付物

- 一篇可连续阅读的叙事正文，而非事件流水账
- 一张分层时间线：智能观念 / 技术 / 资本组织 / 产品系统
- 每个关键节点的证据卡片
- 美国与中国的对照章节
- LLM → RAG → Tool Calling → Agent → Harness 的概念演化图
- 术语表、人物表、机构表和来源索引

## 研究边界

“2026-10-01”是课程的截止日期目标。尚未发生的事件不能提前写成事实；未来部分只能预留章节，待事件发生后补证据并提交新版本。
