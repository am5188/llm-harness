# 课程入口：从图灵到 Harness

这不是一份模型发布目录，而是一门回答“为什么大语言模型会出现”的历史课。

## 阅读路线

```text
图灵提出问题
  ↓
符号主义与连接主义争论智能是什么
  ↓
数据、GPU、深度学习让表示可以被学习
  ↓
Transformer 让训练规模真正可扩展
  ↓
预训练、规模律、RLHF 让模型从续写变成可交互助手
  ↓
ChatGPT 把研究成果变成大众产品
  ↓
LLaMA / Qwen / DeepSeek 让能力扩散到开放生态
  ↓
RAG、工具调用、Agent、Harness 把模型接入真实世界
```

## 读者应该带着的问题

- “智能”是被写进规则里的，还是从规模化数据中学出来的？
- 为什么 2017 年 Transformer 出现后，还要等到 2022 年才有 ChatGPT？
- 为什么有论文并不等于有产品？资本、云和数据劳动分别起了什么作用？
- 为什么 Meta 的开放权重会改变产业结构？
- 为什么 Agent 不是简单地“给模型加一个循环”？

正文将沿着叙事推进，时间线和证据卡片用于查证，而不是替代理解。
