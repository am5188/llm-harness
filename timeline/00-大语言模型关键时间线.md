# 大语言模型关键时间线（初稿）

| 时间 | 事件 | 意义 |
|---|---|---|
| 1950-10（发表） | 图灵《Computing Machinery and Intelligence》 | 模仿游戏把机器智能转化为可观察的语言行为问题（E-0008） |
| 1955-08-31（提案；活动于 1956 夏） | Dartmouth AI 暑期研究项目提案 | 组织化提出语言、概念形成、问题求解和自我改进议程（E-0009） |
| 1970s–1990s | AI 冬天与连接主义积累 | 符号系统扩展性受限；反向传播等工作保留从数据学习表示的路线（E-0010） |
| 2012-09（论文/竞赛结果） | AlexNet 在 ImageNet 突破 | 约 130 万图像、GPU 与深层 CNN 形成可扩展工程示范（E-0011） |
| 2014 | seq2seq、GAN 等快速发展 | 现代生成模型与语言建模的重要前置 |
| 2015 | OpenAI 成立为非营利研究机构 | 前沿研究组织与资本进入新阶段 |
| 2017 | Transformer 论文发表 | 提供可高度并行、可扩展的语言模型架构 |
| 2018 | BERT、GPT-1 | 预训练—微调范式成熟 |
| 2019 | GPT-2；微软与 OpenAI 重要投资合作 | 规模化模型与产业基础设施结合 |
| 2020 | GPT-3；OpenAI API | 少样本能力和模型即服务受到关注 |
| 2020 | DeepMind 等开展规模化研究 | 后续 scaling laws 与计算最优研究基础 |
| 2022-03 | Chinchilla 论文（公开于 2022） | 强调参数与训练 token 的计算最优配比 |
| 2022-11-30 | ChatGPT 发布 | 对话产品将基础模型能力普及到大众 |
| 2023-02 | Meta 发布 LLaMA | 开放权重推动研究与创业生态扩散 |
| 2023-07 | Llama 2 发布 | 更广泛的研究与商业使用许可 |
| 2023 | 中国大模型产品密集发布 | 国内产业进入规模化竞争阶段 |
| 2024-12-26 | DeepSeek-V3 发布 | 强调高效训练与开放权重 |
| 2025-01 | DeepSeek-R1 发布 | 推理模型与强化学习路线引发全球关注 |

## 时间线使用说明

- “发布”要区分论文预印本、研究报告、API、权重和面向公众的产品。
- “开源”要注明是 source-available、open-weight 还是 OSI 意义上的开源。
- 后续为每个节点补充一手来源、关键人物、技术条件、资本条件和对 Harness 的影响。
