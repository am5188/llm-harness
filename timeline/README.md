# 时间线研究总目录

## 目标

建立从机器智能概念、AI 学科、统计学习、深度学习到大语言模型和 Harness 的可验证发展史。时间线不是事件清单，而是“技术条件—组织条件—资本条件—基础设施—社会劳动—产品形态”的因果研究索引。

## 阶段划分

1. **1950–1956：问题与学科起点**
   - 图灵的模仿游戏
   - Dartmouth 研究议程
2. **1957–1980：早期符号主义与感知机**
   - 感知机、LISP、早期专家系统
3. **1980–2006：连接主义复兴与 AI 冬天**
   - 反向传播、统计学习、算力与数据瓶颈
4. **2006–2014：深度学习重新成为主线**
   - 深度信念网络、ImageNet、GPU、词向量
5. **2014–2017：序列建模与注意力**
   - seq2seq、注意力、Transformer
6. **2018–2020：预训练与规模化**
   - BERT、GPT、GPT-3、Scaling Laws
7. **2021–2022：计算最优、对齐与对话产品**
   - Chinchilla、SFT、RLHF、ChatGPT
8. **2023–至今：开放权重、推理模型与 Harness**
   - LLaMA、Qwen、DeepSeek、工具调用、Agent Harness

## 研究矩阵

每个阶段都回答：

- 当时解决了什么问题？
- 哪项技术使它成为可能？
- 数据从哪里来？
- 需要什么算力、能源和基础设施？
- 谁提供资本与组织能力？
- 谁承担标注、评测和维护劳动？
- 哪些论文、项目或产品改变了扩散速度？
- 中国与美国分别处于什么位置？
- 对下一阶段产生了什么可验证影响？
