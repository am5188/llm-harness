# E-0015｜Bahdanau Attention：动态读取源序列

### 2014-09-01｜预印本首次提交；2015｜ICLR 论文

- **事件类型**：预印本 / 会议论文 / 注意力机制
- **事实**：Bahdanau、Cho 与 Bengio 提出在生成每个目标词时，动态计算源序列各位置的软对齐权重，而不是把整句信息固定压进单一向量；论文在神经机器翻译实验中比较了固定表示与动态对齐模型。
- **影响**：注意力让解码器可以在生成过程中反复选择输入序列的相关位置，缓解了长句信息压缩瓶颈；这是后续自注意力和 Transformer 的重要前置问题。
- **与时间线的关系**：事实：预印本首次提交于 2014-09-01。解释：注意力不是“让模型突然理解语言”，而是改变了序列信息被读取和对齐的方式。
