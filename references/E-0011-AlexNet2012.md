# E-0011｜AlexNet 2012：GPU 使深度学习成为可扩展工程

### 2012-09｜ImageNet 大规模视觉识别挑战赛论文公开

- **事件类型**：论文 / 竞赛结果
- **事实**：Krizhevsky、Sutskever、Hinton 训练了一个含约 6000 万参数、约 50 万神经元的深层卷积网络，在约 130 万张高分辨率 ImageNet 训练图像、1000 类任务上取得 top-1 error 39.7%、top-5 error 18.9%。作者采用两块 NVIDIA GTX 580 GPU 训练，并使用非饱和神经元、GPU 卷积实现、dropout 等方法。
- **影响**：论文把数据规模、深度网络、GPU 计算和正则化组合成可复现的性能跃迁，推动视觉研究与产业广泛转向深度学习。它不是语言模型，但证明了“增加数据与计算、让网络学习表示”可以成为工程路线，为后来词表示、序列模型和 Transformer 的规模化提供组织与基础设施信心。
- **与时间线的关系**：事实：2012 年 AlexNet 在 ImageNet 取得显著领先。解释：它移除的是深度网络训练的算力/性能可行性瓶颈之一，不是直接解决语言理解；从视觉到语言还需词向量、序列建模、注意力和大规模文本数据。
